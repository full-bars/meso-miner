## Quick start

Install on Linux:

```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/meso-miner/refs/heads/main/scripts/Provider_Install_Linux.sh | sh
```

Install on macOS:

```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/meso-miner/refs/heads/main/scripts/Provider_Install_Mac.sh | sh
```

Run a provider container. Replace `AUTH_CODE_HERE` with a single-use auth code and `/path/to/proxy.txt` with your proxy file:

```sh
docker run -d --name urfix --pull=always --restart=unless-stopped \
  --cap-add=NET_ADMIN --cap-add=NET_RAW --sysctl net.ipv4.ip_forward=1 \
  -e BUILD=jwt -v urfix_config:/root/.urnetwork \
  -v /path/to/proxy.txt:/app/proxy.txt \
  ghcr.io/full-bars/meso-miner:latest AUTH_CODE_HERE
```

The installer uses this fork's latest GitHub release. For native downloads, replace `<tag>` with the release tag and `<arch>` with `amd64` or `arm64`.

| Platform | Provider archive | Management tool |
| --- | --- | --- |
| Linux | `urnetwork-provider-<tag>-linux-<arch>.tar.gz` | `urnet-tools-linux-<arch>` |
| macOS | `urnetwork-provider-<tag>-darwin-<arch>.tar.gz` | `urnet-tools-darwin-<arch>` |
| Windows | `urnetwork-provider-<tag>-windows-<arch>.tar.gz` | `urnet-tools-windows-<arch>` |
| FreeBSD | `urnetwork-provider-<tag>-freebsd-<arch>.tar.gz` | `urnet-tools-freebsd-<arch>` |
| All platforms | `urnetwork-provider-<tag>.tar.gz` | See platform assets above |

## What changed

- **IPv6 egress isolation.** We fail Windows IPv6 dials when the selected interface cannot be pinned, instead of silently accepting an IPv4-only pin. This prevents traffic following a tunnel route. We have not run this path on a Windows host for this release. [redeploy]
- **Fair capacity and reconnect accounting.** We keep capacity waiters in order, retain grants until consumed or abandoned, and wake followers on cancellation. We also exclude locally canceled H1 attempts from backend failure accounting and stop proxy failures from striking a platform address family. [redeploy]
- **Stored identities.** We skip unchanged JWT store rewrites, preserve entries without mint timestamps, count completed writes and report all changes in mixed batches. A rate-limited log line explains write and skip causes without exposing tokens. [redeploy]
- **Proxy cleanup.** We use persisted down clocks for degraded proxies and restart those clocks during outage and trim holds. Degraded eviction stays opt-in and needs a configured window. [redeploy]
- **Handshake diagnostics.** We report H1+ failures by class. The class metric partitions the existing total; do not add both together. SOCKS5 hop failures are counted as proxy connection failures. [redeploy]
- **Extender capability.** Linux provider updates attempt to restore the privileged-port bind capability after binary swaps and installer rollback. Check warnings if restoration fails. The extender remains opt-in and unproven. [redeploy]
- **Metrics and tools.** We honor `URNETWORK_METRICS=off`, `false`, `no`, `0` and `none`; `auto` chooses automatic binding. The macOS wrapper now forwards proxy refresh and remove-dead arguments. We removed a duplicate down count from proxy health output. [redeploy]
- **Documentation.** We updated troubleshooting, capacity and configuration guidance and refreshed the Bittensor numbers.

[redeploy] means the running provider or its installer must be updated to receive the change.
