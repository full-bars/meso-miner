# Next release

I have prepared this release to add proxy UDP coverage verification, status command enhancements, extender carrier controls and gossip diagnostics. The release also includes the top dashboard with proxy heatmap visualization, Linux interface byte counters and direct blocklist table sync.

Update and restart the provider to use the binary changes.

Legend: **[redeploy]** needs the new provider, tool or container image. **[installer]** needs the updated installer or script. **[no redeploy]** covers documentation, CI and tests.

## Upgrade notes

**Providers on a `v2026.11.1-*-meso` release: update to `v2026.11.15` or later.** Those builds drop client UDP (DNS, STUN, QUIC) through proxied identities. Only TCP works. The fix shipped in `v2026.11.6-1091259400-meso`.

Why it matters: the platform checks UDP (HTTP/3) on each connection. A connection that fails the check does not qualify for the quality bucket. The network sends less traffic to that node than to an otherwise equal node that passes, and it promotes quality bucket nodes more. So UDP support is a direct financial incentive.

The same rule applies to your proxies. Choose proxies that relay UDP. A proxy with no UDP relay shows as `no UDP` in `top` and `status`. See the Proxy Management guide.

## Quick start

Install on Linux:

```sh
curl -fSsL https://raw.githubusercontent.com/urfoundation/meso-miner/refs/heads/main/scripts/Provider_Install_Linux.sh | sh
```

Install on macOS:

```sh
curl -fSsL https://raw.githubusercontent.com/urfoundation/meso-miner/refs/heads/main/scripts/Provider_Install_Mac.sh | sh -s -- install
```

Install on FreeBSD from a non-root service account with `sudo`:

```sh
fetch -qo urnet-install.sh https://raw.githubusercontent.com/urfoundation/meso-miner/refs/heads/main/scripts/Provider_Install_FreeBSD.sh
sudo sh urnet-install.sh install
```

Install on OpenBSD:

```sh
ftp -o urnet-install.sh https://raw.githubusercontent.com/urfoundation/meso-miner/main/scripts/Provider_Install_OpenBSD.sh
doas env SERVICE_USER_OVERRIDE=urnet sh urnet-install.sh install
```

For Docker, pull `ghcr.io/urfoundation/meso-miner:latest`. See the [Docker deployment guide](docs/Docker-Deployment.md) for setup and persistent state mounts.

## Operator actions

- **Extender carrier settings. [redeploy]** You can configure optional extender carriers independently with `urnet-tools set extender-udp443|extender-udp4053|extender-udp53 on|off`. Successfully changing a setting restarts the active extender role automatically. A failed write does not restart a healthy role.
- **Extender discovery default. [redeploy]** Discovery now defaults to on when the extender role runs. Explicit saved `off` or `feed-only` settings are preserved. If you want discovery to remain off on an upgraded node, run `urnet-tools set extender-discovery off`.
- **Background proxy UDP sweeps. [redeploy]** Background sweeps check online proxies periodically. You can stop new sweeps with `urnet-tools set udp-probe off`. Client checks continue running. Re-enable sweeps with `urnet-tools set udp-probe on`.
- **Automation and status scripts. [redeploy]** Scripts can run `urnet-tools status --brief` for fast health checks. It returns exit codes 0 for healthy, 1 for warning, 2 for broken, and 3 for unreachable. Output is empty when healthy. Use `--json-summary` for the stable `urnet-tools-status/1` schema document.
- **Head tier and proxy slots:** A provider that sends the proxy header counts at no head tier unit. Bind direct devices only, and keep a direct slot on the host that you bind.

## What changed

### Added

- **Proxy UDP coverage and background sweeps. [redeploy]** The provider verifies proxy UDP support in background sweeps and preserves results across restarts. A proxy whose UDP check runs over 20 seconds counts as unknown and is allowed. Proxies are never rejected or graded down for lacking UDP and only client UDP and QUIC flows are refused through a proxy proven not to relay. The probe state file is written in the background at most every 2 seconds. Shutdown can request an immediate state flush.
- **Status summary model and output options. [redeploy]** `urnet-tools status` provides a one-screen summary covering version, update checks, proxy counts, UDP relay coverage, extender state and resources. `--brief` provides script exit codes (0 healthy, 1 warning, 2 broken, 3 unreachable) and prints nothing when healthy. `status --json` keeps printing the raw snapshot. `--json-summary` emits the `urnet-tools-status/1` schema. `--live` refreshes the summary in place.
- **Extender carrier controls and DNS 53 telemetry. [redeploy]** Settings `extender-udp443`, `extender-udp4053` and `extender-udp53` control optional carriers independently. Extender status reports port 53 bind state and failure reasons. The gauge metric `urnet_extender_dns53_state` reports the active port 53 state.
- **Gossip node hardening and discovery defaults. [redeploy]** The gossip node bounds inbound streams per connection and node resources, refusing extra streams without harming existing peers. Peer dials are restricted to the selected dialer and addresses. Extender role and discovery default to on, so this hardening protects default installs.
- **Extender gossip event visibility. [redeploy]** A bounded ring buffer records mesh peering events, connection transitions and anomaly dumps. `urnet-tools extender events` displays recent events. It supports `--since`, `--kind` and `--json`.
- **Top dashboard enhancements and Docker integration. [redeploy]** The top screen renders proxy activity as heatmap dots with a configurable afterglow track and shows a UDP coverage row. The proxy heatmap spreads small pools over the whole panel. Top graphs follow the refresh speed: `+` and `-` change the graphs together with the metrics. `urnet-docker top` checks for the dashboard binary before launch and forwards terminal color preferences.
- **Pinned IP family route hold and failed causes. [redeploy]** This is new dial behavior for pinned transports. A pinned IP family with no route is backed off for 5 minutes, doubling up to 1 hour on repeated failures. A network change or connection ends the hold. Authentication and contract error lines now name the failed causes.
- **Linux interface byte counters. [redeploy]** The `internal/nicstat` package reads cumulative receive and transmit bytes from `/proc/net/dev`.
- **Extender sysctl port route. [redeploy]** Linux setup can configure `net.ipv4.ip_unprivileged_port_start=443` to allow unprivileged binding of TCP 443. The port 53 sysctl threshold exists in the setup code but `extender setup` does not select it yet.
- **Proxy heatmap popup. [redeploy]** Hover or click a dot in the `top` proxy heatmap to see that proxy's address (host and port only), state, UDP check result, clients, bytes in the interval and age. The direct connection is counted and shown apart from the proxies. A cell that holds two proxies shows each as one half of the cell, and the popup lists both.

### Fixed

- **Proxy isolation for DoH and extender carriers. [redeploy]** A provider running through a configured proxy no longer resolves platform names over DoH from the host address and does not open host packet sockets for proxied extender carriers.
- **Consistent backend failure state. [redeploy]** The backend failure count and timestamp are published together through one atomic snapshot.
- **Proxy password parsing. [redeploy]** `proxy add` accepts passwords with an @ sign when supplied in URL format.
- **Carrier rollback on control error. [redeploy]** A failed carrier setting write restores the previous carrier configuration and no longer restarts a healthy extender role. A failed live restart is reported to the caller instead of success.
- **Gossip health transitions under cap pressure. [redeploy]** Cap pressure retains a more severe gossip health state.
- **Status review corrections and top copy failure handling. [redeploy]** The status update cache is read safely without following symbolic links, and status honors `--pid`. Running `top --copy` fails the command when the copy cannot be saved to disk. When elevated, directory ownership is handed to the right user without following symbolic links. Status displays an unavailable or stopped extender role correctly. Healthy `--brief` returns exit code 0 with clean output.
- **`top` redraws less and scales its graphs to what is on screen. [redeploy]** The dashboard redraws at most 20 times a second. It used to redraw on every poll result and mouse move, over 100 times a second at a fast refresh. The graph axes follow the visible columns, so one old burst no longer makes live traffic draw one pixel high. Dropped, connecting and dead proxies have their own colors (orange, violet and bold red), and the throughput shades stay in green to aqua. The fade menu item is named `Dot fade time`.
- **Proxied providers keep ICMP and peer connections off the host. [redeploy]** A provider that runs through a proxy opens no host ICMP echo socket and makes no peer-to-peer connections. Its platform connections carry the header `X-UR-Egress-Proxy: 1`. The platform counts a provider that sends the header at no head tier, capture-the-flag or extender unit.
- **A refused yamux memory reservation resets one stream. [redeploy]** When the gossip node's memory budget is full, the affected stream is reset and the connection and its other streams stay up. The release carries a patched copy of go-yamux (`third_party/go-yamux`, MPL-2.0, see `THIRD_PARTY_LICENSES.md`).

### Changed

- **Messaging network prefix list refreshed. [redeploy]** The messaging network prefix list is refreshed from registry route objects.
- **Direct CFAA blocklist sync. [no redeploy]** The CFAA sync commits generated tables straight to main after format and decoder checks pass.
- **Help text and usage alignment. [redeploy]** Commands list real flags in help output. Positional target syntax is removed from usage lines in favor of standard target flags.
- **The UDP row says `no UDP`. [redeploy]** `top`, `status` and the status snapshot show a proxy without a UDP relay as `no UDP` (`no-udp` in narrow views). Logs and metrics keep the state name `no-relay`.
- **Docker images and release archives include the license texts. [installer]** Archives carry a `LICENSES/` directory and images carry `/usr/share/doc/urnetwork/LICENSES/`, including the license of the vendored yamux copy.
- **The README lists Linux, macOS and Windows before the BSDs. [no redeploy]**

## Known limits

- The port 53 sysctl threshold exists in the setup code but `extender setup` does not select it yet. UDP 53 binding requires `CAP_NET_BIND_SERVICE` or root privilege.
- An UNVERIFIED part of the IPv6 hold is timer and standby behavior.
- Proxied identities do not relay client UDP to IPv6 destinations.
