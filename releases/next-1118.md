# Next release

I have prepared this release to add proxy UDP coverage verification, status command enhancements, extender carrier controls and gossip diagnostics. The release also includes the top dashboard with proxy heatmap visualization, Linux interface byte counters and direct blocklist table sync.

Update and restart the provider to use the binary changes.

Legend: **[redeploy]** needs the new provider, tool or container image. **[installer]** needs the updated installer or script. **[no redeploy]** covers documentation, CI and tests.

## Quick start

Install on Linux:

```sh
curl -fSsL https://raw.githubusercontent.com/urfoundation/meso-miner/refs/heads/main/scripts/Provider_Install_Linux.sh | sh
```

Install on macOS:

```sh
curl -fSsL https://raw.githubusercontent.com/urfoundation/meso-miner/refs/heads/main/scripts/Provider_Install_Mac.sh | sh -s -- install
```

Install on FreeBSD from a non-root service account with `sudo`:

```sh
fetch -qo urnet-install.sh https://raw.githubusercontent.com/urfoundation/meso-miner/refs/heads/main/scripts/Provider_Install_FreeBSD.sh
sudo sh urnet-install.sh install
```

Install on OpenBSD:

```sh
ftp -o urnet-install.sh https://raw.githubusercontent.com/urfoundation/meso-miner/main/scripts/Provider_Install_OpenBSD.sh
doas env SERVICE_USER_OVERRIDE=urnet sh urnet-install.sh install
```

For Docker, pull `ghcr.io/urfoundation/meso-miner:latest`. See the [Docker deployment guide](docs/Docker-Deployment.md) for setup and persistent state mounts.

## Operator actions

- **Extender carrier settings. [redeploy]** You can configure optional extender carriers independently with `urnet-tools set extender-udp443|extender-udp4053|extender-udp53 on|off`. A setting change restarts the active extender role automatically.
- **Extender discovery default. [redeploy]** Discovery now defaults to on when the extender role runs. Explicit saved `off` or `feed-only` settings are preserved. If you want discovery to remain off on an upgraded node, run `urnet-tools set extender-discovery off`.
- **Background proxy UDP sweeps. [redeploy]** Background sweeps check online proxies periodically. You can stop new sweeps with `urnet-tools set udp-probe off`. Client checks continue running. Re-enable sweeps with `urnet-tools set udp-probe on`.
- **Automation and status scripts. [redeploy]** Scripts can run `urnet-tools status --brief` for fast health checks. It returns exit codes 0 for healthy, 1 for warning, 2 for broken, and 3 for unreachable. Output is empty when healthy. Use `--json-summary` for the stable `urnet-tools-status/1` schema document.

## What changed

### Added

- **Proxy UDP coverage and background sweeps. [redeploy]** The provider verifies proxy UDP support in background sweeps and preserves results across restarts. A proxy whose UDP check runs over 20 seconds counts as unknown and is allowed. Proxies are never rejected or graded down for lacking UDP and only client UDP and QUIC flows are refused through a proxy proven not to relay. The probe state file is written in the background at most every 2 seconds. Shutdown can request an immediate state flush.
- **Status summary model and output options. [redeploy]** `urnet-tools status` provides a one-screen summary covering version, update checks, proxy counts, UDP relay coverage, extender state and resources. `--brief` provides script exit codes (0 healthy, 1 warning, 2 broken, 3 unreachable) and prints nothing when healthy. `status --json` keeps printing the raw snapshot. `--json-summary` emits the `urnet-tools-status/1` schema. `--live` refreshes the summary in place.
- **Extender carrier controls and DNS 53 telemetry. [redeploy]** Settings `extender-udp443`, `extender-udp4053` and `extender-udp53` control optional carriers independently. Extender status reports port 53 bind state and failure reasons. The gauge metric `urnet_extender_dns53_state` reports the active port 53 state.
- **Extender gossip event visibility. [redeploy]** A bounded ring buffer records mesh peering events, connection transitions and anomaly dumps. `urnet-tools extender events` displays recent events. It supports `--since`, `--kind` and `--json`.
- **Top dashboard enhancements and Docker integration. [redeploy]** The top screen renders proxy activity as heatmap dots with a configurable afterglow track and shows a UDP coverage row. `urnet-docker top` checks for the dashboard binary before launch and forwards terminal color preferences.
- **Linux interface byte counters. [redeploy]** The `internal/nicstat` package reads cumulative receive and transmit bytes from `/proc/net/dev`.
- **Extender sysctl port route. [redeploy]** Linux setup can configure `net.ipv4.ip_unprivileged_port_start=443` to allow unprivileged binding of TCP 443. The port 53 sysctl threshold is not selectable in setup yet.

### Fixed

- **Consistent backend failure state. [redeploy]** The backend failure count and timestamp are published together through one atomic snapshot.
- **Proxy password parsing. [redeploy]** `proxy add` accepts passwords with an @ sign when supplied in URL format.
- **Carrier rollback on control error. [redeploy]** A failed carrier control write restores the previous carrier configuration and restarts the role.
- **Gossip health transitions under cap pressure. [redeploy]** Cap pressure retains a more severe gossip health state.
- **Status review corrections. [redeploy]** The update cache replaces symbolic links with a regular file and honors `--pid`. Status displays an unavailable or stopped extender role correctly. Healthy `--brief` returns exit code 0 with clean output.

### Changed

- **Direct CFAA blocklist sync. [no redeploy]** The CFAA sync commits generated tables straight to main after format and decoder checks pass.
- **Help text and usage alignment. [redeploy]** Commands list real flags in help output. Positional target syntax is removed from usage lines in favor of standard target flags.

### CI and tests

- Tests verify carrier edge cases, gossip ring bounds, status output schemas and Docker top detection.
- The wiki link lint confirms that all markdown links within documentation resolve properly.

## Known limits

- The port 53 sysctl threshold is not selectable in setup yet. UDP 53 binding requires `CAP_NET_BIND_SERVICE` or root privilege.
- Proxied identities do not relay client UDP to IPv6 destinations.
