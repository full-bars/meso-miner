# Next release

Previous release: [v2026.11.15-1099303040-meso](https://github.com/full-bars/meso-miner/releases/tag/v2026.11.15-1099303040-meso).

I prepared this release to add proxy UDP relay coverage checks, extender UDP carrier controls, gossip observability, and a redesigned status summary. The update also includes the consolidated full-screen dashboard in container images.

Update and restart the provider to apply binary changes. Changing an extender carrier setting restarts an active extender role automatically.

Legend: **[redeploy]** needs the new provider, tool or container image. **[installer]** needs the updated installer or script. **[no redeploy]** covers documentation, CI and tests.

## Quick start

Already running a provider? Update it in place:

```sh
urnet-tools update
```

Install on Linux:

```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/meso-miner/refs/heads/main/scripts/Provider_Install_Linux.sh | sh
```

Install on macOS:

```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/meso-miner/refs/heads/main/scripts/Provider_Install_Mac.sh | sh -s -- install
```

Install on Windows in PowerShell:

```powershell
irm https://raw.githubusercontent.com/full-bars/meso-miner/refs/heads/main/scripts/Provider_Install_Win32.ps1 -OutFile "$env:TEMP\install-win.ps1"
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\install-win.ps1"
```

Install on FreeBSD:

```sh
fetch -qo urnet-install.sh https://raw.githubusercontent.com/full-bars/meso-miner/refs/heads/main/scripts/Provider_Install_FreeBSD.sh
sudo sh urnet-install.sh install
```

Install on OpenBSD:

```sh
ftp -o urnet-install.sh https://raw.githubusercontent.com/full-bars/meso-miner/main/scripts/Provider_Install_OpenBSD.sh
doas env SERVICE_USER_OVERRIDE=urnet sh urnet-install.sh install
```

For Docker, pull `ghcr.io/full-bars/meso-miner:latest`.

## Operator actions

- **Extender carrier settings. [redeploy]** Operators can control UDP carriers independently with `urnet-tools set extender-udp443 on|off`, `urnet-tools set extender-udp4053 on|off` and `urnet-tools set extender-udp53 on|off`. A setting change restarts the active extender role automatically and persists across reboots.
- **Extender discovery default. [redeploy]** Extender discovery defaults to on when the extender role runs. Explicit saved settings for `off` and `feed-only` remain in effect.
- **Scripted health checks. [redeploy]** `urnet-tools status --brief` exits with code 0 for healthy, 1 for warning, 2 for broken and 3 for unreachable. Output is empty when healthy. `urnet-tools status --json` keeps printing the raw snapshot. Automation expecting a fixed format can use `urnet-tools status --json-summary`.

## What changed

### Proxies and UDP

- **Proxy UDP coverage checks. [redeploy]** The provider sweeps online proxies in the background to verify UDP relay capability. Status and metrics report coverage counts. Proxies are never rejected or graded down for lacking UDP, and only client UDP and QUIC flows are refused through a proxy proven not to relay. A proxy whose UDP check runs over 20 seconds counts as unknown and is allowed. Background sweeps can be paused with `urnet-tools set udp-probe off`.
- **Probe state persistence. [redeploy]** The probe state file is written in the background at most every 2 seconds. The provider restores previous results across restarts.
- **Proxy password parsing. [redeploy]** The `proxy add` parser accepts passwords that contain an `@` sign.

### Extender and gossip

- **Extender UDP carriers and port 53 telemetry. [redeploy]** Extender status and the `urnet_extender_dns53_state` metric show whether UDP port 53 is bound or why it failed. A failed carrier configuration write restores the previous carrier settings. The port 53 sysctl threshold is not selectable in setup yet.
- **Gossip observability. [redeploy]** Gossip diagnostics report dial attempts, dial failures, health state transitions and bounded anomaly dumps. The `urnet-tools extender events` command displays recent mesh, dial, reject and cap events. Cap pressure does not hide worse gossip health states.

### Status and dashboard

- **Status summary redesign. [redeploy]** Default `urnet-tools status` output presents a one-screen health overview. It shows update availability, proxy pools, UDP coverage, extender state and system resource usage. Update checks use a cache that ignores symbolic links. Status honors `--pid` to inspect a specific process.
- **Consolidated top dashboard and container support. [redeploy]** `urnet-tools top` renders proxy health as heatmap dots with a configurable fading glow track. The dashboard includes a UDP coverage row, interactive mouse panels and a decimal unit toggle. Docker images include the dashboard binary. `urnet-docker top` checks that the binary exists before launching.
- **Linux interface counters. [redeploy]** The tool reads Linux network interface byte counters from `/proc/net/dev`. Counters that reset between snapshots are handled cleanly.

### Security and maintenance

- **Atomic backend failure snapshots. [redeploy]** Backend failure counts and timestamps are published together in one atomic record to prevent mismatched reads.
- **CFAA blocklist sync. [no redeploy]** The CFAA sync commits generated tables straight to main after running format and decoder tests.
- **Unused client window removed. [no redeploy]** The unused FP2 client window and its exported Go API types were removed. Shipped binaries did not use them.

## Known limits

- Extender setup does not offer the lower sysctl threshold for port 53 yet. Binding port 53 as a non-root user requires manual configuration.
- UDP relay verification requires reachability to network endpoints and does not test IPv6 proxy destinations.
