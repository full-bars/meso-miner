# v2026.11.20-1103478850-meso

**Released:** 2026-11-20.

Previous release: [v2026.11.15-1099303040-meso](https://github.com/full-bars/meso-miner/releases/tag/v2026.11.15-1099303040-meso).

I prepared this release to add proxy UDP relay coverage checks, extender UDP carrier controls, gossip observability, and a redesigned status summary. The update also includes the consolidated full-screen dashboard in container images.

Update and restart the provider to apply binary changes. Successfully changing an extender carrier setting restarts an active extender role automatically.

Legend: **[redeploy]** needs the new provider, tool or container image. **[installer]** needs the updated installer or script. **[no redeploy]** covers documentation, CI and tests.

## Upgrade notes

**Providers on a `v2026.11.1-*-meso` release: update to `v2026.11.15` or later.** Those builds drop client UDP (DNS, STUN, QUIC) through proxied identities. Only TCP works. The fix shipped in `v2026.11.6-1091259400-meso`.

Why it matters: the platform checks UDP (HTTP/3) on each connection. A connection that fails the check does not qualify for the quality bucket. The network sends less traffic to that node than to an otherwise equal node that passes, and it promotes quality bucket nodes more. So UDP support is a direct financial incentive.

The same rule applies to your proxies. Choose proxies that relay UDP. A proxy with no UDP relay shows as `no UDP` in `top` and `status`. See the Proxy Management guide.

## Quick start

Already running a provider? Update it in place:

```sh
urnet-tools update
```

Install on Linux:

```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/meso-miner/refs/heads/main/scripts/Provider_Install_Linux.sh | sh
```

Install on macOS:

```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/meso-miner/refs/heads/main/scripts/Provider_Install_Mac.sh | sh -s -- install
```

Install on Windows in PowerShell:

```powershell
irm https://raw.githubusercontent.com/full-bars/meso-miner/refs/heads/main/scripts/Provider_Install_Win32.ps1 -OutFile "$env:TEMP\install-win.ps1"
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\install-win.ps1"
```

Run the provider in Docker. Use a single-use auth code from https://ur.io and keep the state volume:

```sh
docker run -d \
  --name=urnetwork \
  --pull=always \
  --restart=unless-stopped \
  --cap-add=NET_ADMIN \
  --cap-add=NET_RAW \
  --sysctl net.ipv4.ip_forward=1 \
  --log-driver=json-file \
  --log-opt max-size=10m \
  --log-opt max-file=3 \
  -e AUTH=authcode \
  -e AUTHCODE='YOUR_AUTH_CODE_HERE' \
  -e HOST_HOSTNAME=$(hostname) \
  -v urnetwork_data:/root/.urnetwork \
  -v /path/to/proxy.txt:/app/proxy.txt \
  ghcr.io/full-bars/meso-miner:latest
```

Remove the `proxy.txt` line if you do not use proxies. If you already run a provider, reuse your existing volume name instead of `urnetwork_data`.

See the [Docker deployment guide](https://github.com/full-bars/meso-miner/wiki/Docker-Deployment) for Compose files and more options.

Install on FreeBSD:

```sh
fetch -qo urnet-install.sh https://raw.githubusercontent.com/full-bars/meso-miner/refs/heads/main/scripts/Provider_Install_FreeBSD.sh
sudo sh urnet-install.sh install
```

Install on OpenBSD:

```sh
ftp -o urnet-install.sh https://raw.githubusercontent.com/full-bars/meso-miner/main/scripts/Provider_Install_OpenBSD.sh
doas env SERVICE_USER_OVERRIDE=urnet sh urnet-install.sh install
```

## Operator actions

- **Extender carrier settings. [redeploy]** Operators can control UDP carriers independently with `urnet-tools set extender-udp443 on|off`, `urnet-tools set extender-udp4053 on|off` and `urnet-tools set extender-udp53 on|off`. Successfully changing a setting restarts the active extender role automatically and persists across reboots. A failed write leaves a running role untouched.
- **Extender discovery default. [redeploy]** Extender discovery defaults to on when the extender role runs. Explicit saved settings for `off` and `feed-only` remain in effect.
- **Scripted health checks. [redeploy]** `urnet-tools status --brief` exits with code 0 for healthy, 1 for warning, 2 for broken and 3 for unreachable. Output is empty when healthy. `urnet-tools status --json` keeps printing the raw snapshot. Automation expecting a fixed format can use `urnet-tools status --json-summary`.
- **Head tier and proxy slots:** A provider that sends the proxy header counts at no head tier unit. Bind direct devices only, and keep a direct slot on the host that you bind.

## What changed

### Proxies and UDP

- **Proxy UDP coverage checks. [redeploy]** The provider sweeps online proxies in the background to verify UDP relay capability. Status and metrics report coverage counts. Proxies are never rejected or graded down for lacking UDP, and only client UDP and QUIC flows are refused through a proxy proven not to relay. A proxy whose UDP check runs over 20 seconds counts as unknown and is allowed. Background sweeps can be paused with `urnet-tools set udp-probe off`. ([9557a1b](https://github.com/full-bars/meso-miner/commit/9557a1bd3f56e9091579dc8a3991d03fb95cd202), [4a8b259](https://github.com/full-bars/meso-miner/commit/4a8b25928bbee7068166c9702e8f072a3ecb6ea6), [a431dd7](https://github.com/full-bars/meso-miner/commit/a431dd73efbcd27ea92eed98ca7c36e209250889))
- **Proxy isolation for DoH and extender carriers. [redeploy]** A provider that runs through a configured proxy no longer resolves platform names over DoH from the host address and does not open host packet sockets for proxied extender carriers. ([14ef175](https://github.com/full-bars/meso-miner/commit/14ef1756b3b4db0659cf1d52199668fa832691b5))
- **Probe state persistence. [redeploy]** The probe state file is written in the background at most every 2 seconds. The provider restores previous results across restarts. ([3faf051](https://github.com/full-bars/meso-miner/commit/3faf05177a3e5da828bc170627e414e157cc60bd), [41d33c5](https://github.com/full-bars/meso-miner/commit/41d33c591f6da4c4d0f8e6088a9c81da7b91a021))
- **Proxy password parsing. [redeploy]** The `proxy add` parser accepts passwords that contain an `@` sign. ([9353bd8](https://github.com/full-bars/meso-miner/commit/9353bd81a254548585f465fca3a4c4df0badfe2b))
- **Proxied providers keep ICMP and peer connections off the host. [redeploy]** A provider that runs through a proxy opens no host ICMP echo socket and makes no peer-to-peer connections. Its platform connections carry the header `X-UR-Egress-Proxy: 1`. The platform counts a provider that sends the header at no head tier, capture-the-flag or extender unit. ([10a1565](https://github.com/full-bars/meso-miner/commit/10a1565b128bb0c79609a975301ae7df447f840f), [813c20b](https://github.com/full-bars/meso-miner/commit/813c20b8ce606e7cd0bd5b5189694c2af96ad934))
- **The UDP row says `no UDP`. [redeploy]** `top`, `status` and the status snapshot show a proxy without a UDP relay as `no UDP` (`no-udp` in narrow views). Logs and metrics keep the state name `no-relay`. ([37a9059](https://github.com/full-bars/meso-miner/commit/37a9059c7559128c398f54c9016c5a8ba22a72bf))

### Extender and gossip

- **Extender UDP carriers and carrier rollback. [redeploy]** Extender status and the `urnet_extender_dns53_state` metric show whether UDP port 53 is bound or why it failed. A failed carrier setting write restores previous carrier settings and no longer restarts a healthy extender role. A failed live restart is reported to the caller instead of success. Setting the port 53 threshold needs `extender setup --route=sysctl --udp53`. ([f352d4a](https://github.com/full-bars/meso-miner/commit/f352d4aed3737c92d864ad765cf61c9be14040a1), [7c2c105](https://github.com/full-bars/meso-miner/commit/7c2c105eeb869deec66d532cc816bfac465b4ee4), [ac8127f](https://github.com/full-bars/meso-miner/commit/ac8127f924c4779135eb3eccedc8469c31487da9))
- **Gossip node hardening and discovery defaults. [redeploy]** The gossip node bounds inbound streams per connection and node resources, refusing extra streams without harming existing peers. Peer dials are restricted to the selected dialer and addresses. Extender role and discovery default to on, so this hardening protects default installs. ([a8b0cc5](https://github.com/full-bars/meso-miner/commit/a8b0cc5e1f284a5664976b10624df965542eee5d), [56761b7](https://github.com/full-bars/meso-miner/commit/56761b7dc77e5239bc5c76f496b8dcf6f6b9b900), [0479a46](https://github.com/full-bars/meso-miner/commit/0479a4607f1baa19d773c5a2f0a241ba5fe108ca))
- **Gossip observability. [redeploy]** Gossip diagnostics report dial attempts, dial failures, health state transitions and bounded anomaly dumps. The `urnet-tools extender events` command displays recent mesh, dial, reject and cap events. Cap pressure does not hide worse gossip health states. ([9f8aff2](https://github.com/full-bars/meso-miner/commit/9f8aff2170f606e8839925a0537f98b1fca97e39), [3cca687](https://github.com/full-bars/meso-miner/commit/3cca687351eccaeb68f3be055784b1247930689d), [dd1aab3](https://github.com/full-bars/meso-miner/commit/dd1aab318329cec392aec60f1078ba02bdd944b0))
- **A refused yamux memory reservation resets one stream. [redeploy]** When the gossip node's memory budget is full, the affected stream is reset and the connection and its other streams stay up. The release carries a patched copy of go-yamux (`third_party/go-yamux`, MPL-2.0, see `THIRD_PARTY_LICENSES.md`). ([02dd5ba](https://github.com/full-bars/meso-miner/commit/02dd5bacc82785f5f68251b4f289e4f2222fbb79), [2d15dec](https://github.com/full-bars/meso-miner/commit/2d15dec1c850f7ea7484d5e887d031051502b74d))
- **`extender setup --udp53` lowers the bind threshold for UDP port 53. [redeploy]** On Linux, `urnet-tools extender setup --route=sysctl --udp53` sets `net.ipv4.ip_unprivileged_port_start` to 53 after you type `yes`. Any local user can then bind ports 53 to 1023, and the command says so before it asks. `--force` does not confirm it. Other platforms and routes refuse the flag. `extender status` shows whether the threshold is in force. ([bd28ce2](https://github.com/full-bars/meso-miner/commit/bd28ce2755a5bd596801a74b65955a3ff61c9fbb), [b68281d](https://github.com/full-bars/meso-miner/commit/b68281dbc542d5c91fc1343084802e33009b08b6))

## Known limits

- Without `--udp53`, `extender setup` does not lower the port 53 threshold. Binding port 53 as a non-root user then requires manual configuration.
- An UNVERIFIED part of the IPv6 hold is timer and standby behavior.
- UDP relay verification requires reachability to network endpoints and does not test IPv6 proxy destinations.
