# v2026.11.6-1091658360-meso

**Released:** 2026-11-06

**Previous release:** `v2026.11.1-1087111111-meso`

I ported Ryanmello07's UDP relay support for proxied clients. I also made proxy maintenance and provider lifecycle operations safer and added progress reports and failure diagnostics.

**[redeploy]** means update the affected provider, management tool or container image. **[installer]** means use the updated installer or uninstaller. **[no redeploy]** means documentation or test changes only.

## Quick start

Install on Linux:

```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/meso-miner/refs/heads/main/scripts/Provider_Install_Linux.sh | sh
```

Install on macOS:

```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/meso-miner/refs/heads/main/scripts/Provider_Install_Mac.sh | sh -s -- install
```

Run a provider container. Replace `AUTH_CODE_HERE` with a single-use auth code and `/path/to/proxy.txt` with your proxy file:

```sh
docker run -d --name urfix --pull=always --restart=unless-stopped \
  --cap-add=NET_ADMIN --cap-add=NET_RAW --sysctl net.ipv4.ip_forward=1 \
  -e BUILD=jwt -v urfix_config:/root/.urnetwork \
  -v /path/to/proxy.txt:/app/proxy.txt \
  ghcr.io/full-bars/meso-miner:latest AUTH_CODE_HERE
```

The installer uses this fork's latest GitHub release. The container uses `$HOME/.urnetwork` for state. A failed proxy import keeps a valid saved configuration; without one, startup stops. Without a mounted proxy file, startup is not blocked. The container shell wrapper does not implement `direct`, `usage`, `rename` or `sn-status` as native commands. See the Docker deployment guide for supported alternatives.

For native downloads, replace `<tag>` with `v2026.11.6-1091658360-meso` and `<arch>` with `amd64` or `arm64`.

## What's changed

### Proxy traffic and maintenance

- **Proxied client UDP uses the proxy relay.** **[redeploy]** ([#345](https://github.com/full-bars/meso-miner/pull/345)) Each flow opens its own SOCKS5 UDP association. A failed relay check or a known TCP and UDP exit mismatch refuses the flow. If the check is unknown, including when it times out or cannot determine the TCP exit, the flow may use an unverified exit. It never falls back to the host address. IPv6 destinations are refused because the check proves only IPv4. Proxied UDP flows close when either sends or replies are idle for 120 seconds; TCP is unchanged.
- **Refresh previews match the reloader.** **[redeploy]** ([#343](https://github.com/full-bars/meso-miner/pull/343)) The preview uses the same desired set as the reload, including the URL cache. If the cache cannot be read, the reload protects proxies whose desired state is unknown.
- **Degraded URL proxy cleanup uses a persisted down clock.** **[redeploy]** ([#335](https://github.com/full-bars/meso-miner/pull/335)) A missing clock is backfilled. Outage and trim holds restart the clock. Degraded eviction remains opt-in: an unset or invalid window does not remove degraded members.
- **Windows IPv6 dials honor the selected egress interface.** **[redeploy]** ([#342](https://github.com/full-bars/meso-miner/pull/342)) An IPv6 pin failure is reported instead of accepting an IPv4-only pin. The Windows-only test was compiled but was not run on a Windows host for that port.

### Capacity and identity

- **Capacity waiters keep their place.** **[redeploy]** ([#341](https://github.com/full-bars/meso-miner/pull/341)) Earlier eligible waiters are protected from starvation. Grants remain accounted for until used or abandoned, and cancellation wakes followers. Independent child budgets and impossible requests do not block unrelated eligible work.
- **Local cancellations do not count as backend failures.** **[redeploy]** ([#341](https://github.com/full-bars/meso-miner/pull/341)) A locally cancelled H1 attempt no longer feeds the reconnect governor as a failure. Proxy handshake failures no longer strike the platform address family or trigger family retries.
- **JWT store writes report actual changes.** **[redeploy]** ([#337](https://github.com/full-bars/meso-miner/pull/337), [#341](https://github.com/full-bars/meso-miner/pull/341)) Unchanged stores skip the disk rewrite. A rate-limited log reports the cause and counts without printing tokens. Entries without mint times are retained, mixed changes are counted and writes count as complete only after they succeed.

### Lifecycle and installers

- **Uninstall stops the provider before removing files.** **[redeploy]** ([#347](https://github.com/full-bars/meso-miner/pull/347)) On Windows, the management tool checks for processes that may share the profile and verifies exit and socket closure. On Unix it stops the systemd, OpenRC, FreeBSD rc.d or standalone process and checks the PID and socket. A failed stop or an unconfirmed exit aborts removal. The full Windows uninstall was not run on a real profile; the PR reports Windows host tests with controlled processes and test seams.
- **Windows start, stop and restart protect shared profiles.** **[redeploy]** ([#347](https://github.com/full-bars/meso-miner/pull/347)) Stop and restart refuse when another provider may share the profile. Start avoids a duplicate when it detects a running provider. If the process list fails, it warns and checks the socket only. Update and tune restart a running provider through the Windows route; a stopped provider stays stopped. Force stop preserves a socket with a live listener.

- **The Windows PowerShell uninstaller waits for exit.** **[installer]** ([#347](https://github.com/full-bars/meso-miner/pull/347), [#349](https://github.com/full-bars/meso-miner/pull/349)) It recognizes the legacy install path, waits up to 15 seconds and aborts before removing files if a provider remains, another provider may share the data, or process checks fail. Its wait block was exercised with a controlled process, not the full uninstall against a real profile.
- **Linux swaps restore the extender bind capability when possible.** **[installer]** ([#338](https://github.com/full-bars/meso-miner/pull/338), [#346](https://github.com/full-bars/meso-miner/pull/346), [#349](https://github.com/full-bars/meso-miner/pull/349)) The installer attempts to restore `cap_net_bind_service` after swaps and successful rollback. It checks the bounding set before applying the capability and removes a blocked file capability only when no unrelated capability would be lost.
- **Updater and container swaps restore the capability too.** **[redeploy]** ([#340](https://github.com/full-bars/meso-miner/pull/340), [#346](https://github.com/full-bars/meso-miner/pull/346), [#349](https://github.com/full-bars/meso-miner/pull/349)) The Go updater and container scripts attempt restoration and check the bounding set. The image includes the capability utilities. The extender role remains opt-in and does not activate or serve traffic yet. Check warnings if restoration fails.
- **The macOS shell wrapper forwards proxy options.** **[installer]** ([#339](https://github.com/full-bars/meso-miner/pull/339)) `proxy refresh` and `proxy remove-dead` pass their arguments to the provider. In particular, `remove-dead --preview` no longer loses the preview flag.

### Diagnostics and metrics

- **H1+ handshake failures are classified.** **[redeploy]** ([#336](https://github.com/full-bars/meso-miner/pull/336)) The log and `urnet_h1plus_handshake_failures_class_total` separate failure classes. The classes partition the existing total, so do not add both metrics together. SOCKS5 hop failures are classified as proxy connection failures; a timeout remains a timeout.
- **Proxy fetch and probe report progress.** **[redeploy]** ([#346](https://github.com/full-bars/meso-miner/pull/346)) Logs name the source, report downloaded line counts and provide periodic probe progress.
- **Proxy health no longer repeats the down count.** **[redeploy]** ([#334](https://github.com/full-bars/meso-miner/pull/334)) The `down` field is removed; `dead` and `degraded` remain. Update log parsers that require `down`.
- **Metrics environment settings work as intended.** **[redeploy]** (`c61638a61`) `URNETWORK_METRICS=off`, `false`, `no`, `0` or `none` disables the listener; `auto` selects automatic binding. The environment overrides saved state. Remove the environment setting before enabling metrics through the control tool.
