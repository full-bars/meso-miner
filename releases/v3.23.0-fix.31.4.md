# v3.23.0-fix.31.4

> [!CAUTION]
> **FINAL NOTICE: the hub subsystem is being deprecated.** The next release series removes the hub entirely. Hub mode operators must plan their migration now. The 31.x series is the last that ships the hub.

## What's Changed

### Bug Fixes

- **fix(transfer): forget unreliable flight on resend timeout instead of releasing it** — Fixed a congestion-control bug. A resend timeout halved the flight window, but the old release path grew the window back on the same timeout. The reduction never stuck. Timeouts now only shrink the window. Successful deliveries are the only event that grows it. (<https://github.com/full-bars/urnetwork-3.23-fix/pull/640>)

- **fix(transfer): commit held receive items before acknowledging them** — Fixed a receiver dishonesty bug. The receiver acknowledged held items on arrival, then evicted already-acknowledged items to admit earlier arrivals. The sender learned nothing until a full 60-second lease expired. The receiver now acknowledges an item only when it can no longer be evicted. Evicted items were never acknowledged, so the sender recovers with a cheap resend instead of a stalled minute. (<https://github.com/full-bars/urnetwork-3.23-fix/pull/641>)

### Maintenance

- **chore(security): sync CFAA blocklist from upstream** — Refreshed the content filtering blocklist. (<https://github.com/full-bars/urnetwork-3.23-fix/pull/637>)

- **docs: H3 + miner migration plan** — Added a plan document for the future migration to the upstream H3 transport and the Bittensor miner daemon. No behavior changes. (<https://github.com/full-bars/urnetwork-3.23-fix/pull/639>)

- **docs(release): add hub deprecation callout to v31.3 notes** — Amended the v31.3 release notes with the deprecation notice. (<https://github.com/full-bars/urnetwork-3.23-fix/pull/635>)

- **docs(release): switch v31.3 hub callout to CAUTION** — Raised the deprecation notice severity. (<https://github.com/full-bars/urnetwork-3.23-fix/pull/636>)

## Deploy Notes

1. **The two transfer fixes are the headline of this release.** Under packet loss the provider now halts window growth on timeout and stops withdrawing acknowledgements. Lossy routes recover faster and duplicate retransmit traffic drops.
2. **Hub mode operators must move.** The hub ships in this release and the next, then is removed. Use `urnet-tools` to update, or reinstall with the standard provider setup.
3. **CFAA blocklist updates take effect on the next reload.** No restart is required.
