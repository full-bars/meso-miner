# v2026.11.9-1094055530-meso

**Released:** 2026-11-09.

Previous release: `v2026.11.9-1093990130-meso`.

I made this release so the Docker image for the previous release could build. The previous tag has release binaries but its Docker build failed, because three CI checks were red. I fixed the checks, made one wording change and fixed two update and setup bugs.

Legend: **[redeploy]** needs the new provider, tool or container image. **[installer]** needs the updated installer or script. **[no redeploy]** covers documentation, CI and tests.

## What's changed

- **The hotswap message names the old installer script. [redeploy]** When a unit is still `Type=simple`, the message now says that older versions of `Provider_Install_Linux.sh` wrote it. The current installer writes `Type=notify`.
- **The OpenRC update check no longer runs the provider image as root. [redeploy]** The verify step now picks the read-only version reader first. Before, it ran the image once and then discarded the result.
- **Setup applies the sysctl route once for several providers. [redeploy]** The route is host-wide. Before, a second provider made setup fail with "backup already exists" or back up its own drop-in.
- **The Docker image builds again. [redeploy]** The `:latest` image moves to this release.
- **The installer test stub understands `sudo -n`. [no redeploy]** The shell suite now runs to the end. Before, it stopped silently after about 70 checks. A new check proves no installer step can wait for a sudo password.
- **An extender test no longer depends on the host. [no redeploy]** It stubs provider discovery. A new test proves the elevated setup refuses an anonymous target.

## Known limits

- The installer and updater paths were tested with stubbed system commands. They were not run on a production host.
- If you run the previous release, nothing needs to change. Update when it suits you.
