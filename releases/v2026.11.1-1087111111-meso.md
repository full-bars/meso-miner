# v2026.11.1-1087111111-meso

**Released:** not yet. Built from `main` after `v2026.10.24-1080497440-meso` (`d43ca1ff`). The `[Unreleased]` section of `CHANGELOG.md` is the source.
**Previous release:** `v2026.10.24-1080497440-meso`. This file does not repeat that release or earlier ones.

Legend: **[redeploy]** needs the new artifact. **[installer]** needs the installer or unit refresh. **[no redeploy]** is docs, CI or tests only.

> [!NOTE]
> Most changes are installer and Docker startup fixes. The proxy probe and the proxy lock also changed. A FreeBSD provider installer is new (#309). The extender role is unfinished and does not run on the fleet. This release does not change that.

> [!IMPORTANT]
> Three changes can break a script or a habit.
> - `--i-am-on-my-own-workstation` is gone. `urnet-tools wallet` warns and carries on. Remove the flag from scripts (#322, `0be2a806`).
> - The contract log has a ` | ` between the verb and the proxy tag (`71c08375`). A grep for `acquired proxy[` no longer matches. `[contract] acquired` still matches.
> - Before this release, a macOS `urnet-tools` update staged the Linux binary and refused it. No macOS update could finish (#323).

## What broke and is fixed

- **macOS `urnet-tools` update.** It picked the Linux binary. It now picks `darwin/<arch>/provider` from the universal tarball. **[redeploy]** ([#323](https://github.com/full-bars/meso-miner/pull/323), `9e20bcaa`). Unit-tested only. Not run on a Mac.
- **Docker updater `version.txt`.** The updater took the version from the asset URL. If the URL was not `/download/v<tag>/`, it wrote the URL. Every later check then saw a stale box and downloaded the archive again. The updater now records the parsed tag. It refuses to install without one. **[redeploy]** ([#330](https://github.com/full-bars/meso-miner/pull/330), `8146e3a9`).
- **Pelican panel script.** It read only `AUTHCODE`. A container with `URNETWORK_AUTH_CODE` ran `auth-provide` with an empty code. It now reads both. **[redeploy]** ([#328](https://github.com/full-bars/meso-miner/pull/328), `75d33684`).
- **Network switch.** A preset network switch warns about a stale token again. **[redeploy]** ([#324](https://github.com/full-bars/meso-miner/pull/324), `3cc1e129`).
- **`urnet-tools logs --important`.** It follows the newer of the two files. **[redeploy]** ([#324](https://github.com/full-bars/meso-miner/pull/324), `b7ad8a09`).
- **FreeBSD discovery.** It now asks the kernel for execute access with `access(2)` `X_OK`. **[redeploy]** (`e718d31a`, `0333138b`).
- **Extender source.** A source that asks again at once now gets an answer. **[redeploy]** (`db1abbcc`).
- **URL fetch failures.** The reason now stays in the important log. **[redeploy]** ([#305](https://github.com/full-bars/meso-miner/pull/305), `bbc48004`).
- **RAM log trim.** It no longer holds the writer's lock. **[redeploy]** ([#307](https://github.com/full-bars/meso-miner/pull/307), `9b7ea765`, `6e84da18`).
- **Windows paste prompt.** It names the key that ends input. **[redeploy]** ([#311](https://github.com/full-bars/meso-miner/pull/311), `a8ccb228`, `dc95aafb`).

## Provider behaviour

- **IPv6 memory per proxy carrier.** **[redeploy]** ([#331](https://github.com/full-bars/meso-miner/pull/331), `a539bfce`, `eed8234a`).
  - Before: an exit with no IPv6 made every v6 dial wait for its timeout.
  - Now: after 3 failed explicit v6 dials in a row through one carrier, the provider stops offering v6 on that carrier for 15 minutes.
  - A skipped v6 dial fails at once. The dial race moves to v4.
  - When the 15 minutes end, the provider lets one probe dial through. If it works, the carrier is clear. If it fails, the 15 minutes start again.
  - The provider retries a failing exit only after the cooldown ends.
  - Failures more than 10 minutes apart do not add up. The count starts over (`eed8234a`).
  - Carriers do not share a verdict.
  - The memory applies only to explicit `tcp6`/`udp6` dials and v6 literals. See `net_carrier_ipv6.go`.
- **Probe.** It asks every resolved address before it marks a route bad. A v6-only target is sent as `atyp ipv6` (`53368e28`). A round cut short by the limiter gives no verdict. **[redeploy]** ([#304](https://github.com/full-bars/meso-miner/pull/304), `2f5dc8cb`, `d2798e69`, `18df836f`).
- **Proxy lock.** The proxy state is written under one lock. **[redeploy]** ([#317](https://github.com/full-bars/meso-miner/pull/317), `f206be32`, `83929b64`, `f7f25cf7`, `db4a1a05`, `1c4652c6`).
  - Startup holds the cross-process lock for its whole read-modify-write.
  - `proxy remove --match` removes and excludes under one lock.
  - `proxy remove --all` holds the lock over the config write, the state reset and the URL cache reset.
  - Shutdown no longer waits for a queued reload.
- **Contract log.** The line reads `[contract] acquired | proxy[3] (203.0.113.22:1081) ...`. The direct slot reads `proxy[0] (direct)`. **[redeploy]** (`71c08375`).

## Metrics

The code did not change here. The docs were wrong. This is what the code does.

- `/metrics` is on by default (`84904557`, in the previous release).
- Default mode is `auto`. The provider takes the first free port from 9100 to 9103.
- Outside a container, `auto` listens on `127.0.0.1` and on each Tailscale IPv4 address. It never uses a public interface.
- In a container, `auto` normally listens on `0.0.0.0` inside the container. Other containers or hosts with a route to it can reach it even without a published port. If the container detects a public address on its network, it falls back to loopback and Tailscale.
- Port 9091 is not used anywhere. Pages that said 9091 are fixed (`f6eb3151`, `80433ba9`).
- To pin an address, set `URNETWORK_METRICS=<ip:port>` or run `urnet-tools metrics listen <ip:port>`. The second form survives restarts.
- To turn `/metrics` off, run `urnet-tools metrics off`. The setting survives restarts, unless `URNETWORK_METRICS` is set. Remove that variable too to keep metrics off across restarts and HotSwap.
- Do not set `URNETWORK_METRICS=off`, `=0` or `=auto`. The variable is a bind address. Those values fail to bind. Any value in it also overrides a saved `metrics off`.

## Wallet

- **The fleet seed-file check warns. It does not refuse.** **[redeploy]** (`0be2a806`).
  - `urnet-tools wallet sign` and `wallet set --coldkey_seed_file` print a warning when the box also runs a provider. Then they carry on.
  - The warning says a fleet node should not hold a coldkey.
  - The `--coldkey_seed_file` warning is loud and goes to stderr. That form no longer asks you to type `yes`, so it runs with no terminal. `--dry-run` still stops before the provider. The warning cannot be turned off.
  - The first version of this check (#322) refused. `0be2a806` changed it.
- **`--i-am-on-my-own-workstation` is gone.** It does nothing. The tool warns by name and carries on, so old scripts keep working. ([#322](https://github.com/full-bars/meso-miner/pull/322), `11983d0e`). Signing has no gate to skip.

## Installers

- **FreeBSD provider installer, new.** **[installer]** ([#309](https://github.com/full-bars/meso-miner/pull/309)).
  - It installs the flat FreeBSD tarball into `/usr/local/libexec/urnetwork-provider`.
  - The tree belongs to `root:wheel`. Group and other cannot write.
  - The service user owns only the state directory.
  - `sysrc` sets `urnetwork_enable` and `urnetwork_user` only if they are unset.
- **Both installers check the provider archive before they extract it.** **[installer]** ([#316](https://github.com/full-bars/meso-miner/pull/316)).
  - They compare the archive with its SHA-256 digest.
  - FreeBSD refuses a release that lists the archive without a digest.
  - Linux warns once and continues.
  - The installer stages the new binary and renames it into place. If the restart fails, it restores the old binary.
- **FreeBSD installer checks `urnet-tools` and the tree.** **[installer]** ([#314](https://github.com/full-bars/meso-miner/pull/314), `a9b6203d`, `1e0c246a`, `444a3a52`). A missing digest, a failed download or a mismatch stops the install. A symlink in the install tree stops it too.
- **FreeBSD backup order.** **[installer]** ([#332](https://github.com/full-bars/meso-miner/pull/332), `77ae151a`, `2cb32b5f`).
  - The installer now installs the new `urnet-tools` only after the provider backup exists. A failed backup used to leave the new tool next to the old provider.
  - It clears its backup record only when the backup file is really gone.
  - If the file cannot be removed, the installer says it is left on disk. The exit cleanup then tries again.
  - The backup survives a failed exit.
- **Linux backup copy.** **[installer]** ([#328](https://github.com/full-bars/meso-miner/pull/328), `2ac876fd`, `20a8e86a`).
  - A failed copy to `urnetwork.old` now stops the install before the swap. It removes the staged file.
  - After a failed restart, the installer says it restored the old binary only if the move back worked. Otherwise it names what is left on disk and skips the second start.
- **FreeBSD rc.d start.** It keeps the log of the previous run. The running check sees a provider that has not yet exec'd. **[installer]** (`766968be`, `587b81f5`).
- **FreeBSD staged files.** The installer removes them with the privilege that made them. **[installer]** (`d64a8fd1`).

## Docker

- **Startup keeps valid sessions and proxy settings.** **[redeploy]** ([#319](https://github.com/full-bars/meso-miner/pull/319), `7e592460`, `e1a1c7ca`, `c5713691`).
  - The auth code now reaches the binary.
  - A nightly start reuses a valid saved JWT.
  - A mounted `/app/proxy.txt` is imported into a staging directory. It replaces the saved config only if it gave valid servers.
  - If the import fails and no valid saved config exists, startup stops with `Proxy import failed and no configuration is saved`.
  - With no `/app/proxy.txt`, startup is not blocked.
- **A bad provider environment setting stops startup** before authentication. **[redeploy]** (`15abf295`).
- **The IP checker downloads to a temporary file.** A failed fetch logs `IP checker fetch failed`. **[redeploy]** ([#319](https://github.com/full-bars/meso-miner/pull/319)).
- **Docker does not read `URNETWORK_STATE_DIR`.** The scripts use `$HOME/.urnetwork`. A change that read the variable was reverted (`0ee2d308`). The provider ignores a shell-only override.
- **vnStat is retired.** `ENABLE_VNSTAT` is still accepted. It only logs a warning. No traffic UI runs on port 8080. The README, configuration, Docker, multi-container and Pelican pages now say so. **[no redeploy]** ([#333](https://github.com/full-bars/meso-miner/pull/333), `97342d5b`).

## Security

- **The h3 relay dial error no longer carries proxy credentials.** **[redeploy]** ([#332](https://github.com/full-bars/meso-miner/pull/332), `a9398b1c`, `a659b408`, `36ec630b`).
  - The dial error used to repeat the address it was given. That address could hold userinfo or a token path. It reached the operator log.
  - The error now holds a redacted proxy address and a short failure class, such as `timed out`.
  - A cancelled context returns the context error, so callers can still tell a shutdown from a dead relay.
  - Error text also redacts proxy addresses and store keys. Tests cover both (`provider/h3_packet_conn.go`).
- **Docker auth debug output hides echoed credentials.** The match ignores case and trims the address. **[redeploy]** ([#319](https://github.com/full-bars/meso-miner/pull/319), `9cca7995`, `8f8b06de`).
- **FreeBSD root writes are fenced.** The state-directory `chown` no longer recurses into a tree the service user owns. **[installer]** ([#309](https://github.com/full-bars/meso-miner/pull/309)).
- **Blocklist sync.** **[redeploy]** ([#306](https://github.com/full-bars/meso-miner/pull/306), [#308](https://github.com/full-bars/meso-miner/pull/308), [#313](https://github.com/full-bars/meso-miner/pull/313), [#329](https://github.com/full-bars/meso-miner/pull/329)). This is data only.

## What to do

1. **Provider nodes, any platform:** deploy the new binary. It carries the probe, proxy-lock, IPv6, contract-log and Docker changes.
2. **FreeBSD nodes:** run the installer again. It reads release metadata with `awk` when `jq` and `python3` are missing.
3. **Docker nodes:** pull or rebuild the image.
4. **Scripts that call `urnet-tools wallet`:** remove `--i-am-on-my-own-workstation`.
5. **Scripts that grep the contract log:** use the new separator.
6. **Scripts that disable metrics with `URNETWORK_METRICS=off`:** use `urnet-tools metrics off`.
7. **Rollback:** stop the unit, restore the old provider binary and state directory, start the unit.
