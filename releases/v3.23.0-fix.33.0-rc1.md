# v3.23.0-fix.33.0-rc1

> [!NOTE]
> Pre-release of the v33 line. It swaps in upstream's platform transport, adds a dual-stack (IPv4 and IPv6) platform connection, and ports the IP layer fixes. Not a stable release: it is invisible to `urnet-tools update`. Try it on one box first.

## Highlights

- **Dual-stack platform transport.** The direct identity connects over IPv4 and IPv6. Switch live with `urnet-tools set ip-version dual|ipv4|ipv6|legacy`. Per-family counters and log lines are included.
- **Upstream transport swapped in.** DNS and DNS-pump carriers are automatic fallbacks on the direct identity. The `h3` key is `off|direct|on`, or a proxy count, or `all`. A SOCKS5 UDP relay and path check carry QUIC for proxied identities. QUIC datagrams are on by default, as upstream.
- **H1+ is on by default again.** The H1 dial is fixed to close losing dials, keep the outage guard, and not fall back on 429/5xx. The framed-upgrade rejection cache is scoped to its route.
- **IP layer.** IPv6 extension headers are walked in the parser. Fragmented IPv4 and IPv6 datagrams are reassembled in the NAT, within a byte budget. A failed upstream dial now answers the source (RST, ICMP unreachable, or nothing on timeout) instead of going silent. An oversized IPv4 UDP reply is fragmented at the IP layer.
- **Signed wallet consent.** The subnet wallet set is signed with the coldkey. Only the documented sign-in challenge is signed and the seed file must be owned by the caller.
- **Credential renewal.** The provider renews its credential when the platform refuses it.
- **Optional client key publication opt-out.** Off by default, and refused whenever encryption is on.

## Fixed

- Windows: refused and timed-out dials are recognised, and the seed file mode rule no longer rejects every seed.
- A disabled transport's early session end is no longer treated as platform evidence.

## Known limits

- Fragment reassembly runs in the local NATs. Fragments arriving at a provider are not reassembled yet.
- ICMP echo is not supported in this RC.
