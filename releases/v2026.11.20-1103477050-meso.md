# v2026.11.20-1103477050-meso

**Released:** 2026-11-20.

I have prepared this release to add proxy UDP coverage verification, status command enhancements, extender carrier controls and gossip diagnostics. The release also includes the top dashboard with proxy heatmap visualization, Linux interface byte counters and direct blocklist table sync.

Update and restart the provider to use the binary changes.

Legend: **[redeploy]** needs the new provider, tool or container image. **[installer]** needs the updated installer or script. **[no redeploy]** covers documentation, CI and tests.

## Upgrade notes

**Providers on a `v2026.11.1-*-meso` release: update to `v2026.11.15` or later.** Those builds drop client UDP (DNS, STUN, QUIC) through proxied identities. Only TCP works. The fix shipped in `v2026.11.6-1091259400-meso`.

Why it matters: the platform checks UDP (HTTP/3) on each connection. A connection that fails the check does not qualify for the quality bucket. The network sends less traffic to that node than to an otherwise equal node that passes, and it promotes quality bucket nodes more. So UDP support is a direct financial incentive.

The same rule applies to your proxies. Choose proxies that relay UDP. A proxy with no UDP relay shows as `no UDP` in `top` and `status`. See the Proxy Management guide.

## Quick start

Install on Linux:

```sh
curl -fSsL https://raw.githubusercontent.com/urfoundation/meso-miner/refs/heads/main/scripts/Provider_Install_Linux.sh | sh
```

Install on macOS:

```sh
curl -fSsL https://raw.githubusercontent.com/urfoundation/meso-miner/refs/heads/main/scripts/Provider_Install_Mac.sh | sh -s -- install
```

Install on Windows in PowerShell:

```powershell
irm https://raw.githubusercontent.com/urfoundation/meso-miner/refs/heads/main/scripts/Provider_Install_Win32.ps1 -OutFile "$env:TEMP\install-win.ps1"
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\install-win.ps1"
```

Run the provider in Docker. Use a single-use auth code from https://ur.io and keep the state volume:

```sh
docker run -d \
  --name=urnetwork \
  --pull=always \
  --restart=unless-stopped \
  --cap-add=NET_ADMIN \
  --cap-add=NET_RAW \
  --sysctl net.ipv4.ip_forward=1 \
  --log-driver=json-file \
  --log-opt max-size=10m \
  --log-opt max-file=3 \
  -e AUTH=authcode \
  -e AUTHCODE='YOUR_AUTH_CODE_HERE' \
  -e HOST_HOSTNAME=$(hostname) \
  -v urnetwork_data:/root/.urnetwork \
  -v /path/to/proxy.txt:/app/proxy.txt \
  ghcr.io/urfoundation/meso-miner:latest
```

See the [Docker deployment guide](https://github.com/urfoundation/meso-miner/wiki/Docker-Deployment) for Compose files and more options.

Install on FreeBSD from a non-root service account with `sudo`:

```sh
fetch -qo urnet-install.sh https://raw.githubusercontent.com/urfoundation/meso-miner/refs/heads/main/scripts/Provider_Install_FreeBSD.sh
sudo sh urnet-install.sh install
```

Install on OpenBSD:

```sh
ftp -o urnet-install.sh https://raw.githubusercontent.com/urfoundation/meso-miner/main/scripts/Provider_Install_OpenBSD.sh
doas env SERVICE_USER_OVERRIDE=urnet sh urnet-install.sh install
```

## Operator actions

- **Extender carrier settings. [redeploy]** You can configure optional extender carriers independently with `urnet-tools set extender-udp443|extender-udp4053|extender-udp53 on|off`. Successfully changing a setting restarts the active extender role automatically. A failed write does not restart a healthy role.
- **Extender discovery default. [redeploy]** Discovery now defaults to on when the extender role runs. Explicit saved `off` or `feed-only` settings are preserved. If you want discovery to remain off on an upgraded node, run `urnet-tools set extender-discovery off`.
- **Background proxy UDP sweeps. [redeploy]** Background sweeps check online proxies periodically. You can stop new sweeps with `urnet-tools set udp-probe off`. Client checks continue running. Re-enable sweeps with `urnet-tools set udp-probe on`.
- **Automation and status scripts. [redeploy]** Scripts can run `urnet-tools status --brief` for fast health checks. It returns exit codes 0 for healthy, 1 for warning, 2 for broken, and 3 for unreachable. Output is empty when healthy. Use `--json-summary` for the stable `urnet-tools-status/1` schema document.
- **Head tier and proxy slots:** A provider that sends the proxy header counts at no head tier unit. Bind direct devices only, and keep a direct slot on the host that you bind.

## What changed

### Added

- **Proxy UDP coverage and background sweeps. [redeploy]** The provider verifies proxy UDP support in background sweeps and preserves results across restarts. A proxy whose UDP check runs over 20 seconds counts as unknown and is allowed. Proxies are never rejected or graded down for lacking UDP and only client UDP and QUIC flows are refused through a proxy proven not to relay. The probe state file is written in the background at most every 2 seconds. Shutdown can request an immediate state flush. ## Known limits

- Setting the port 53 threshold needs `extender setup --route=sysctl --udp53`. UDP 53 binding requires `CAP_NET_BIND_SERVICE` or root privilege.
- An UNVERIFIED part of the IPv6 hold is timer and standby behavior.
- Proxied identities do not relay client UDP to IPv6 destinations.
