> [!IMPORTANT]

A macOS `urnet-tools` update staged the Linux binary and refused it, so no macOS update could finish before this release (#323).

## Installers

- **A FreeBSD provider installer, with the provider in a root-owned tree** **[installer]** ([#309](https://github.com/full-bars/meso-miner/pull/309)). The script installs the release's flat FreeBSD tarball into `/usr/local/libexec/urnetwork-provider`, owned by `root:wheel` with group and other write removed. The state directory is the only part the service user owns. `sysrc` sets `urnetwork_enable` and `urnetwork_user` only when they are unset.
- **The installers verify the provider archive before extracting it** **[installer]** ([#316](https://github.com/full-bars/meso-miner/pull/316)). Linux and FreeBSD both compare the archive with its SHA-256 digest. A FreeBSD release that lists the archive without a digest is refused. The replacement binary is staged and renamed, and a failed restart restores the previous one.
- **The FreeBSD installer refuses an unverifiable `urnet-tools` and a damaged tree** **[installer]** ([#314](https://github.com/full-bars/meso-miner/pull/314), `a9b6203d`, `1e0c246a`, `444a3a52`). A missing digest, a failed download or a mismatch stops the install. A symlink inside the install tree stops it too.
- **FreeBSD discovery requires execute access for the invoking user** **[redeploy]** ([#315](https://github.com/full-bars/meso-miner/pull/315), `e718d31a`). It asks the kernel with `access(2)` `X_OK`.
- **The FreeBSD rc.d start keeps the previous run's log, and the running check sees a provider that has not exec'd yet** **[installer]** (`766968be`, `587b81f5`).
- **FreeBSD staged files are removed with the privilege that created them** **[installer]** (`d64a8fd1`).
- **`urnet-tools` updates on macOS pick the right binary** **[redeploy]** ([#323](https://github.com/full-bars/meso-miner/pull/323), `9e20bcaa`). `darwin` maps to `darwin/<arch>/provider` in the universal tarball. Unit-tested only; not run on a Mac.
- **A preset network switch warns about a stale token again** **[redeploy]** ([#324](https://github.com/full-bars/meso-miner/pull/324), `3cc1e129`).
- **`urnet-tools logs --important` follows the newer of the two files** **[redeploy]** ([#324](https://github.com/full-bars/meso-miner/pull/324), `b7ad8a09`).

## Provider

- **The proxy state is written under one lock** **[redeploy]** ([#317](https://github.com/full-bars/meso-miner/pull/317), `f206be32`, `83929b64`, `f7f25cf7`, `db4a1a05`, `1c4652c6`). Startup holds the cross-process proxy lock across its read-modify-write. `proxy remove --match` removes and excludes under one lock. `proxy remove --all` holds the lock across the config write, state reset and URL cache reset. Shutdown no longer waits on a queued reload.
- **The probe asks every resolved address before it convicts a route** **[redeploy]** ([#304](https://github.com/full-bars/meso-miner/pull/304), `2f5dc8cb`, `d2798e69`, `18df836f`). A v6-only target is encoded as `atyp ipv6` (`53368e28`). A round cut short by the limiter reports no verdict.
- **The URL fetch failure reason stays in the important log** **[redeploy]** ([#305](https://github.com/full-bars/meso-miner/pull/305), `bbc48004`).
- **The RAM log trim stays off the writer's lock** **[redeploy]** ([#307](https://github.com/full-bars/meso-miner/pull/307), `9b7ea765`, `6e84da18`).
- **The contract log separates the proxy tag from the verb** **[redeploy]** (`71c08375`, [#313](https://github.com/full-bars/meso-miner/pull/313)). The line now reads `[contract] acquired | proxy[3] (203.0.113.22:1081) ...`, and the direct slot reads `proxy[0] (direct)`.
- **An extender source that asks again at once is answered** **[redeploy]** (`db1abbcc`).
- **`--i-am-on-my-own-workstation` is removed** **[redeploy]** ([#322](https://github.com/full-bars/meso-miner/pull/322), `11983d0e`). A script that still passes it stops with a message that the flag was removed.
- **The paste prompt names the key that ends input on Windows** **[redeploy]** ([#311](https://github.com/full-bars/meso-miner/pull/311), `a8ccb228`, `dc95aafb`).

## Docker

- **Startup keeps valid sessions and proxy configuration** **[redeploy]** ([#319](https://github.com/full-bars/meso-miner/pull/319), `7e592460`, `e1a1c7ca`, `c5713691`). The auth code reaches the binary. A nightly start reuses a valid saved JWT. A mounted `/app/proxy.txt` is imported into a staging directory and replaces the saved configuration only when it produced valid servers. Startup stops only when no usable configuration remains.
- **An invalid provider environment setting stops startup** **[redeploy]** (`15abf295`), before authentication.
- **The IP checker is downloaded to a temporary file** **[redeploy]** ([#319](https://github.com/full-bars/meso-miner/pull/319)). A failed fetch logs `IP checker fetch failed`.
- **Docker does not read `URNETWORK_STATE_DIR`.** The scripts use `$HOME/.urnetwork`. An earlier change that read it was reverted (`0ee2d308`), because the provider ignores a shell-only override.

## Security

- **Docker auth debug output redacts echoed credentials** **[redeploy]** ([#319](https://github.com/full-bars/meso-miner/pull/319), `9cca7995`, `8f8b06de`). The match is case-normalized and trims the address.
- **The FreeBSD root writes are fenced** **[installer]** ([#309](https://github.com/full-bars/meso-miner/pull/309)). The state-directory `chown` no longer recurses into a tree the service user owns.
- **Blocklists refreshed** **[redeploy]** ([#306](https://github.com/full-bars/meso-miner/pull/306), [#308](https://github.com/full-bars/meso-miner/pull/308), [#313](https://github.com/full-bars/meso-miner/pull/313)). The CFAA table holds 48,764 IPv4 and 539 IPv6 ranges, and the IP blocker 164,781 hosts. Data only.

## Deploy notes

1. **Provider nodes on any platform** need the new binary for the probe, proxy-lock, contract-log and Docker changes above.
2. **FreeBSD nodes** run the installer again to pick up the verified install. The installer reads release metadata with `awk` when `jq` and `python3` are absent, so a bare host no longer needs either.
3. **Docker nodes** need the image rebuilt or pulled. A script that calls `urnet-tools wallet` with `--i-am-on-my-own-workstation` fails until the flag is removed.
4. **Scripts that grep the contract log** need the new separator. See the IMPORTANT note above.
5. **Rollback** is the usual one: keep the previous provider binary and state directory, stop the unit, restore the binary, start.

## Caveats

- The macOS update fix is unit-tested only. The FreeBSD installer changes were read from the code and run in CI, and have not run on a bare FreeBSD host.
- The extender role and the Chrome ClientHello switch are unchanged in this release. The role is a work in progress and unproven; the ClientHello switch is off by default.
- Blocklist counts are data only and take effect once a node runs this build.
